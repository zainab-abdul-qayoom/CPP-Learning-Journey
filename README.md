# C++ Fundamentals Practice

A collection of C++ programs written during my 1st semester, covering everything from basic syntax to arrays, strings, functions, recursion, pointers, and simple OOP-adjacent building blocks. This README organizes the files by topic so anything can be found quickly.

## How to Compile & Run

Each file is a standalone `.cpp` program. Compile and run any file with g++:

```bash
g++ "filename.cpp" -o output
./output
```

(On Windows: `output.exe` instead of `./output`.)

## Topics Covered

- Variables, data types, and operators
- Control flow: if-else, switch, loops, jump statements
- Pattern printing (stars, numbers, pyramids)
- Arrays (1D & 2D) and strings
- Functions and recursion
- Pointers and references
- Storage classes and variable scope
- Structures, unions, and enums
- Basic exception handling and macros
